# 使用设置

## 按 Session 管理开关

插件的开关按 Session 保存，不按工作区保存。这样可以精确控制需要关注的任务：

- 同一个工作区里，可以只打开一个 Session 的悬浮灯；
- 也可以同时打开多个 Session；
- 不同工作区的 Session 互不影响；
- 关闭一个 Session，不会关闭其他悬浮灯。

开关入口位于每个 Session 的三点菜单：

- 「开启红绿灯」：打开当前 Session 的悬浮灯；
- 「关闭红绿灯」：关闭当前 Session 的悬浮灯。

悬浮灯上的右键菜单也提供「关闭悬浮灯」，它只关闭当前对应的 Session。

## 窗口行为

- 每个开启的 Session 对应一个独立悬浮窗。
- 悬浮窗默认保持在其他窗口上方，方便随时查看。
- 多个悬浮窗可以分别拖动和摆放。
- 关闭 DSH Web 或卸载插件时，悬浮窗会随插件退出而关闭。
- 重新启动 DSH 后，需要的 Session 会根据之前的开关状态恢复显示；如果某个 Session 已不存在，则不会创建对应窗口。

## 状态保留

- 运行中和等待关注时，悬浮灯会持续显示当前状态。
- 任务完成后，绿灯会保留一小段时间，避免你错过完成提示。
- 失败或需要关注的状态会保留，直到该 Session 开始新一轮任务，或你在状态页执行重置。
- 空闲时三盏灯熄灭。

这些行为不需要用户手动编辑配置文件。插件安装后即可使用，Session 开关也会自动保存。

## 多个 DSH 实例

同一台电脑上同时运行多个 DSH 实例时，建议一次只为一个实例启用悬浮灯。不同实例如果使用相同的本地运行目录，可能会共享窗口状态，导致显示混淆。

## 权限与隐私

插件只需要 DSH 本身已有的插件运行权限，以及桌面系统创建置顶窗口的能力。状态保存在当前用户的本机目录中，不会上传 Session 内容、提示词或工具结果。

如果系统首次询问桌面窗口或辅助功能权限，请允许 DSH/插件完成窗口创建；拒绝权限可能导致菜单可用但悬浮窗无法显示。

## 网页状态页

插件会随 DSH 提供一个同源状态页，主要用于排查问题。它不是悬浮灯的替代界面，也不需要在日常使用中打开。状态页地址由当前 DSH 地址和 `/dsh-traffic-light/` 组成，例如：

```text
http://127.0.0.1:<DSH端口>/dsh-traffic-light/
```

如果你只想看状态，使用桌面悬浮灯即可；只有在悬浮窗异常时才建议打开状态页辅助排查。
