# dsh-traffic-light 用户文档

`dsh-traffic-light` 是 DeepSeek Harness 的桌面悬浮红绿灯插件。安装后，你可以为每个 Session 单独打开一盏灯，在不切换 DSH 页面时了解任务状态。

## 文档导航

| 文档 | 适合什么时候阅读 |
| --- | --- |
| [快速开始](getting-started.md) | 第一次安装、开启、关闭或卸载插件 |
| [使用设置](configuration.md) | 了解 Session 独立开关、窗口行为和状态保留 |
| [状态说明](architecture.md) | 了解红、黄、绿三盏灯分别代表什么 |

如果你只想马上使用，请直接看仓库首页的 [README](../README.md) 和[安装部分](../README.md#安装)。

安装和日常使用只需要阅读以上三篇说明。
