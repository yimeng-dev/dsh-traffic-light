# 状态说明

这篇文档只解释你在悬浮灯上看到的状态，不需要了解插件内部实现。

## 三盏灯如何表示五种状态

悬浮窗固定显示红、黄、绿三盏灯。黄色有两种动态表现，所以可以区分“正在运行”和“需要你处理”：

| 页面状态 | 悬浮灯表现 | 什么时候出现 |
| --- | --- | --- |
| Running（运行中） | 黄灯慢呼吸 | Session 正在执行任务。 |
| Attention（需要关注） | 黄灯快速闪烁 | DSH 等待你的确认或回答，或者任务暂时受阻。 |
| Completed（已完成） | 绿灯常亮 | 本轮任务正常结束。 |
| Failed（失败） | 红灯常亮 | 本轮任务发生错误或异常中断。 |
| Idle（空闲） | 三灯熄灭 | 当前没有正在执行的任务。 |

## 状态变化示例

一次典型的任务可能按下面的顺序变化：

```text
熄灭（空闲）
    ↓ 开始任务
黄灯慢呼吸（运行中）
    ├─ 等待确认/回答 → 黄灯快闪（需要关注）
    ├─ 正常结束     → 绿灯（已完成）
    └─ 发生异常     → 红灯（失败）
```

当你处理完确认或回答后，Session 会继续运行，悬浮灯会回到黄灯慢呼吸。开始新一轮任务也会清除上一轮的完成或失败提示。

## 多 Session 时如何看

每盏悬浮灯只代表一个 Session：

- 看到哪盏灯闪烁，就在对应的 Session 中处理问题；
- 一盏灯变红，不代表其他 Session 也失败；
- 一盏灯变绿，只表示它对应的 Session 已完成；
- 多盏灯可以同时处于不同状态。

## 绿灯为什么不会立即熄灭

完成提示会短暂保留，方便你在切换窗口或暂时离开电脑时仍能看到结果。下一轮任务开始后，绿灯会立即进入运行状态；等待保留时间结束后，没有新任务的 Session 会恢复熄灭。

## 失败和需要关注为什么会保持

红灯和黄灯快闪表示你可能需要处理结果。它们不会因为 DSH 暂时没有新消息就自动熄灭。你可以：

1. 回到对应 Session 查看详情；
2. 处理确认、回答或错误；
3. 重新开始任务，让灯光进入新一轮状态。

## 状态不一致时怎么办

如果 DSH 页面和悬浮灯显示不一致：

1. 确认看的确实是同一个 Session；
2. 刷新 DSH 页面；
3. 从该 Session 菜单关闭并重新开启悬浮灯；
4. 仍未恢复时重启 `dsh web`。

插件只显示 DSH 已报告的运行状态，不会自行推断终端命令或其他应用的状态。
